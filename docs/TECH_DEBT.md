# Technical debt

## Overview

Readiness gates reject new findings while allowing existing debt to shrink.
Baselines are generated by their checker, never edited by hand. See
[RATCHETS.md](RATCHETS.md) for the shared runner and contributor workflow.

## Ratchets

Current count is `len(findings)` for shared-runner baselines and `len(files)`
for the legacy file-size census. Multiple occurrences can share one finding
key; the runner also enforces each key's occurrence count.

Run checks through `make readiness-lint-root`. Shared-runner JSON reports go
to `READINESS_REPORT_DIR` (default `/tmp/aragora-readiness/ratchet-reports`).
The file-size checker includes tracked and untracked-but-not-ignored Python
files. Other apps can supply repeatable `--glob` patterns and `--baseline`.

## Known debt items

- At adoption, ruff 0.14.14 reports 216 naming occurrences across 191 keys
  and 750 complexity occurrences across 744 keys. C901 is enabled only in
  the readiness ratchet, not the default ruff selection.
- Vulture 2.16 reports 92 occurrences across 67 keys at confidence 80.
- Mypy 2.1.0 found 2,641 missing-definition annotations in 862 modules
  (737 in `aragora/`, 122 in `scripts/`, two in `aragora-debate/`, and one in
  `aragora-verify/`; both small packages inherit the root configuration).
  One sorted override block exempts
  only these explicit module names from `disallow_untyped_defs`; existing
  error-code overrides stay unchanged. The baseline tracks module membership
  (862 keys / 862 occurrences), not annotation counts. Remove modules from
  the block as they become typed, then run the shrink-only update.
- The operator authorized one file-size re-adoption on 2026-09-05 before
  enabling the gate. Three tracked files already exceeded 2,000 lines at
  mission-base but were absent from the original 32-entry census:
  `aragora/server/handlers/receipts.py` (2,041),
  `aragora/swarm/preflight.py` (2,109), and
  `aragora/swarm/quorum_evidence.py` (3,974).
  The tool regenerated the census to 35 entries with
  `frozen_from_ref=0074a58167555387aab1cbf026f03963e156fbcc` and
  `frozen_at=2026-09-05T19:59:22Z`. It is shrink-only again.
